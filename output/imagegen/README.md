# Branding source assets

These files are kept for future branding work and are not shipped with the extension.

- `friction-logo-v3.png` also preserves the original full-size artwork previously stored in `extension/public/assets/app logo/`; SHA-256 comparison confirmed the files were identical. The extension uses the four resized `icon-*.png` files in that directory instead.
- `friction-logo-v1.png` through `friction-logo-v3.png` and their prompts are retained design alternatives; final branding remains undecided.

Shared UI icons are maintained inline in `extension/src/components/common/Icons.jsx`; separate public SVG copies are unnecessary.
