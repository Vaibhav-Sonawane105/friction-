# Challenge pilot worksheet

Use the development build with a test website and test-only counts. This worksheet is for the redesigned challenges, not the previously shared friends’ preview. Aim for five volunteers. Each tries every type at every level three times across multiple sessions; split sessions so fatigue does not dominate. Alternate starting types between volunteers. Do not include personal domains or browsing history.

| Completed unlocks to set | Level | Practiced target | Memory pairs |

Prepare one challenge in the popup and open the site. Time from the first usable prompt to the unlock. Record abandonment separately rather than treating it as a fast completion. Include maths, memory, route and ordering in every level. Record one row per attempt:

| Tester alias | Session | Type | Level | Exposure (1–3) | Seconds | Mistakes | Finished or left | What required thought, or became automatic? |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

Compare the first exposure to the last two. For each type/level, report the practiced median and range, plus abandoned attempts and their reasons. Flag consistently easy types, big differences between people, confusing instructions and shortcut strategies. Adjust profiles only where the observations support it; never add waits just to hit the targets.

Then try normal rotation during ordinary use. Ask: **Did the effort change whether you opened the site? Was there a time you wanted to disable the extension, and why?** Completion time alone cannot answer either question.
